# Operational PostgreSQL and private R2 cold storage

`production/v1/` remains the public country delivery index. `archive/v1/` is private, contains immutable SHA-256-addressed compressed objects, and is never accessible through the public delivery Worker. The separate `speed-camera-archive` Worker requires an Ed25519 signature for GET, HEAD and PUT, expires signatures after 120 seconds, restricts paths and upload size, verifies bytes and refuses replacement. Signed PUTs also support only compact public country snapshots and their manifest; unsigned publication is rejected. Public delivery reads still use the separate read-only Worker. Its public verification key is bound at deployment; the private key stays in ignored, mode-0600 `.env.r2-publisher`. No public archive listing or deletion route exists.

Cold storage holds full source observations, normalized master records, candidates, raw acquisitions, historical snapshots, schema recovery material and import receipts. Dataset manifests record compressed/decoded SHA-256 and row count per shard and overall. Small raw files are bundled into bounded gzip objects with per-file offsets, lengths and original hashes; large files span multiple bundles. `r2_archive.py` performs remote read-back before a manifest can be registered.

PostgreSQL contains published typed camera rows, compact archive/source references, the small UA/PL legacy metadata required by existing clients, the source license catalog, existing user reports, bounded import summaries, old candidate moderation state, one current-master pointer and one archive-registry row per import. New bulk candidates and observations create no PostgreSQL rows. Public country partitions are discovered from the current manifest rather than a fixed country count.

Future imports use `cold_storage_pipeline.sync`: archive source snapshots and pre-dedupe normalized observations first; load the committed R2 master for identity/spatial deduplication; archive every disposition, including duplicates/rejections; archive new candidates and a merged normalized master; read back and check hashes/counts; lock/check the old pointer; register the verified receipt; append only eligible new published cameras; commit the current-master pointer with the canonical writes. A failed archive causes no operational writes. Concurrent imports fail safely. Old canonical rows are never replaced by less reliable evidence. After an operational commit, a delivery-pending flag triggers compact country export, verified immutable upload, a checksum-verified R2 backup of the previous manifest, and manifest publication. A delivery outage preserves the committed canonical data and leaves the flag for retry on the next run. Source catalogs have bounded fields and update by source, not observation.

The existing expansion importer uses this flow automatically when storage v2 is enabled. Local working caches stay inside `master-db/raw`, `master-db/cache` and `master-db/backups` and are ignored by Git. To force fresh feeds, `fetch_expansion_official.main(refresh=True)` and `fetch_expansion_osm.fetch(..., refresh=True)` retain prior source files inside project backups. Primary OSM evidence verification and conservative country/geometry/policy checks remain in place before publication. Acquisition failure retains the prior working feed.

No store release or OTA publication is part of this migration. See [ROLLBACK.md](ROLLBACK.md) for recovery order and retention rules. The migration report records measured storage, receipts and the full typed restoration drill.

Coverage acquisition and measured country gains are documented in [../coverage/README.md](../coverage/README.md). Daily regional OSM extracts add alternate enforcement tags and explicit relation members. The extractor checks free space before downloading, verifies R2 byte restoration before evicting local PBF copies, and reuses already archived snapshots. Approximate way centers remain unpublished candidates. Use `scripts/report_coverage_stage.py` for R2-aware incremental statistics; the earlier expansion report describes its historical pre-migration stage.
