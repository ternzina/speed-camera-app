CamAlert — проверка на физическом Android

Подготовка
[ ] Записать модель телефона, версию Android, версию Waze, дату проверки.
[ ] Подключить телефон к Mac по USB; включить USB debugging и подтвердить разрешение компьютеру.
[ ] Если подключено несколько устройств, выбрать серийный номер перед установкой.
[ ] Проверить подпись уже установленного CamAlert. APK EAS имеет другую подпись, чем Google Play: не удалять существующее приложение без отдельного согласования, поскольку удаление стирает локальные базы, настройки и историю.
[ ] Установить существующий APK на подходящий телефон; убедиться, что Waze установлен.
[ ] В CamAlert выбрать страну и загрузить базу заранее.
[ ] Разрешить точное местоположение, фоновый доступ «Всегда» и уведомления.
[ ] На первом проходе выключить энергосбережение и «Не беспокоить», проверить громкость уведомлений и медиа.
[ ] Все действия с экраном выполнять до начала движения либо поручить пассажиру. Для проверки не превышать скорость.

Карта и стабильность
[ ] Запустить CamAlert три раза: нет зависания/диалога «не отвечает».
[ ] Нажать «Карта», не начиная поездку: дороги, подписи и камеры видны.
[ ] Изменить масштаб и нажать маркер; данные соответствуют выбранной стране.
[ ] Проверить «Камеры» и «Рядом»: приложение не закрывается.

Waze и фон
[ ] В CamAlert выбрать Waze, указать известный адрес/координаты и подтвердить выбор.
[ ] До открытия Waze появляется постоянное уведомление «CamAlert · Фоновая сессия».
[ ] Waze открывает переданный пункт назначения; CamAlert не строит собственный маршрут.
[ ] Проехать с Waze на экране мимо известной камеры из загруженной базы, в направлении её контроля. Записать время, место, скорость, расстояние предупреждения.
[ ] Уведомление CamAlert приходит без ручного возврата в приложение; ограничения скорости показаны корректно.
[ ] Повторить с погашенным экраном в течение 10–15 минут. Служба не исчезает, события продолжают приходить.
[ ] Повторить без мобильного интернета с заранее загруженной базой. Проверять предупреждения, а не наличие офлайн-карты Google/Waze.
[ ] Отдельно повторить с энергосбережением: записать задержки/пропуски и настройки батареи производителя.
[ ] После возвращения в CamAlert отключить фон в настройках либо завершить активную поездку: постоянное уведомление исчезает, новые фоновые события прекращаются.
[ ] После принудительной остановки приложения не ожидать автоматического возобновления; вручную запустить новую сессию.

Звук и голос — проверять отдельно
[ ] Динамик телефона: системный сигнал CamAlert слышен при открытом Waze.
[ ] Bluetooth автомобиля: отметить, куда выводится сигнал (автомобиль/телефон), не теряется ли он во время подсказки Waze.
[ ] Проверить одновременно с музыкой и голосом Waze: нет бесконечного повторения сигналов, звук навигатора возвращается.
[ ] Выключить голос/звук в CamAlert: проверить отсутствие фонового звукового сигнала; отдельно проверить вибрацию.
[ ] Проверить беззвучный режим и «Не беспокоить», зафиксировать реальное системное поведение. Обход этих режимов не обещается.
[ ] На переднем плане проверить голосовую фразу CamAlert; при скорости ниже лимита не должно быть команды снизить скорость.
ВАЖНО: текущая реализация в фоне отправляет системное уведомление со звуковым сигналом. Синтезированная голосовая фраза в фоне пока не реализована. Это отдельный пункт разработки, а не подтверждённая функция APK.

Как фиксировать результат
Для каждого пункта: ПРОЙДЕНО / ОШИБКА / НЕ ПРОВЕРЕНО, время, скриншот и краткое описание.
Логи собирать только для CamAlert; перед передачей скрывать API-ключи и личные координаты/адреса.
